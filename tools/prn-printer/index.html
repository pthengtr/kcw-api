Transfer / sticker printing

KCW PRN Printer

โปรแกรมช่วยพิมพ์ไฟล์ .prn ไปยังเครื่องพิมพ์ TSC บน Windows - แสดงตัวอย่างสติ๊กเกอร์, จำนวนที่พิมพ์ต่อบาร์โค้ด, แล้วส่งพิมพ์แบบ RAW

กำลังโหลดเวอร์ชัน…

ติดตั้งครั้งแรก (แนะนำ)

  1. เปิด PowerShell บน PC ที่ต่อเครื่องพิมพ์ TSC
  2. วางคำสั่งด้านล่างแล้วกด Enter
  3. รอจนขึ้นข้อความติดตั้งสำเร็จ
  4. ดาวน์โหลดไฟล์ .prn จากระบบโอน แล้ว ดับเบิลคลิก เพื่อพิมพ์

อัปเดตเวอร์ชันใหม่

เมื่อมีการปรับปรุง ให้รันคำสั่งติดตั้งเดิมอีกครั้ง - จะเขียนทับของเดิมและคงการเชื่อมไฟล์ .prn

หรือดาวน์โหลด ZIP แล้วรัน Install-PrnPrinter.ps1 ในโฟลเดอร์ที่แตกไฟล์

ถ้ามีเวอร์ชันใหม่ หน้าต่างพิมพ์จะขึ้นแถบเตือนอัปเดตให้อัตโนมัติ

ถอนการติดตั้ง

%LOCALAPPDATA%\KCW\PrnPrinter\Uninstall-PrnPrinter.ps1

หรือใน PowerShell: & "$env:LOCALAPPDATA\KCW\PrnPrinter\Uninstall-PrnPrinter.ps1"

สิ่งที่ได้หลังติดตั้ง

  • ดับเบิลคลิก .prn → หน้าต่างพรีวิว + เลือกเครื่องพิมพ์
  • สรุปจำนวนสติ๊กเกอร์ / บาร์โค้ดที่จะพิมพ์
  • ติดตั้งที่ %LOCALAPPDATA%\KCW\PrnPrinter (ต่อ user, ไม่ต้อง admin)
