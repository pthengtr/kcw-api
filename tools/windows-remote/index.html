IT / remote access

KCW Windows Remote

ติดตั้ง Tailscale + เปิด SSH ให้แอดมินเข้าเครื่องนี้ได้

กำลังโหลดเวอร์ชัน…

  1. กดปุ่มดาวน์โหลดด้านล่าง
  2. คลิกขวาไฟล์ที่ดาวน์โหลด → Run as administrator
  3. ถ้าถามล็อกอิน Tailscale ให้ล็อกอินด้วยบัญชี KCW
  4. เสร็จแล้วส่งชื่อเครื่อง / IP ที่โชว์ท้ายสคริปต์กลับมาหาแอดมิน
ดาวน์โหลดตัวติดตั้ง

Advanced: irm <base>/tools/windows-remote/install.ps1 | iex ใน PowerShell (Run as administrator)
