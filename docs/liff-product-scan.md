# LIFF product scanner (retired)

Product scan no longer uses LIFF.

See **[product-scan.md](./product-scan.md)** for the current LINE camera /
camera-roll flow with barcode decoding inside `kcw-api`.

`KCW_LIFF_PRODUCT_SCANNER_URL` and the kcw-v2 `/liff/scan-product` page are no
longer required for this feature.
