## หลักสำคัญ (สรุปสั้น)

1. Cashflow BI อ่านจาก **ประเภทการจับคู่** (`matched_ref_type`) — ไม่ใส่ → ไปกอง “ยังไม่จัดประเภท / อื่นๆ”
2. **จับคู่ด้วยมือ / ตรวจแล้ว** ต้องมีเหตุผลไทย + ประเภท (บังคับ) + เลขอ้างอิงถ้ามี
3. **ไม่ใช้** = ไม่เข้า Excel / ไม่นับ Cashflow (แถวซ้ำ) — อย่าใช้กับดอกเบี้ย / WHT / โอนภายใน

## ตรวจ chatbot

1. เปิด `/kb` → กด **สร้าง embedding ที่ขาด** (ถ้ามี)
2. ใช้ช่องค้นหาความหมายบน `/kb` ลองถาม เช่น `อาจเป็นแถวซ้ำ`, `ประเภทการจับคู่`, `ดอกเบี้ย ไม่ใช้`
3. จาก LINE ถามด้วย trigger KB ตามปกติ แล้วเลือกหัวข้อที่ตรง
